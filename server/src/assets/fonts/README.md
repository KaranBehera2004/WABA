# Invoice fonts

Noto Sans Regular and Bold are embedded and subset in invoice PDFs so rendering does not depend on fonts installed on the server or customer's computer.

Unmodified fonts from `@expo-google-fonts/noto-sans@0.4.2` (`400Regular/NotoSans_400Regular.ttf` and `700Bold/NotoSans_700Bold.ttf`), by The Noto Project Authors. See `OFL.txt` for the SIL Open Font License 1.1.
